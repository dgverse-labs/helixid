Guided use cases

Select Concierge Agent and ask it to book. Its credential has both read:catalog and write:orders.

Expected: booking succeeds and Console shows VP verification.

Generate a Console token with only read:catalog, onboard it here, then try search and booking from that persona.

Expected: search succeeds; booking is refused for missing write:orders.

Select Concierge Agent in console agent list, revoke its current credential, then ask it to book again. The wallet still signs a VP, but HelixID rejects it because the credential is now revoked.

Expected: retry is refused and Console shows a revoked/failed VP verification.

Create a full-access Planner Agent and no-access Research Agent, then delegate only read:catalog from Planner to Research.

Expected: delegated search succeeds; delegated booking is refused for missing write:orders.
